# Whole-host regional source policy

`ReservedCheckpointInventory.forReservedWidgetSource` derives the bank source
from the actual post-inline host. It selects the supported typed storage
contracts and inert compiler context in original order, validates both, and
binds the original full annotation sequence and retained metadata. The default
`forReservedWidget` path keeps its original NoCircuitDedup-only permission.
Neither path changes the emitted opaque transport or assigns capture ownership.

The new permission checks the pre-inline context before a pass can coalesce
identical options. Its source cannot omit, reorder, duplicate or substitute an
annotation. Global inventory receives exactly the bound typed storage sequence;
the temporary invalid-output transport projection remains analysis-only.
Unknown targeted annotations reject when either their definition or its concrete
execution set changes. This includes unchanged shared leaves whose executions
move into specialized banks and primitive-local annotations that could broaden
to newly added mask gates. Every region is reconstructed from this source
before routes or descriptor identity can be bound. Whole-host typed projection follows concrete original
executions, then validates the union of host and generated contracts. Compiler
context survives banking, common-root grafting and connection unchanged.

The source-policy fixture includes preservation constraints on shared leaves,
a native memory-style hint, a global memory initialization policy, passive
output bytes, configuration context and the actual inline history. The
independent Python auditor reconstructs the source from the full original
sequence and checks source/context snapshots and retained-owner hashes. Its
adversarial tests update the source hashes before testing omissions, ordering,
duplication and substitution. Existing transport routing and identity tests
continue to apply.

This is compiler and transport component work. Complete production common-cut,
reset/external-writer, memory/timing, bridge/host and pre-FAME ownership remains
incomplete. New router/mask/control state still needs capture or a checked
exclusion and restore contract. Generated image/header and physical-clock owner
guards remain mandatory. The actual Rocket image cannot be built until its
FASED physical CE/common-low-phase-cut owner and remaining coverage are bound.
A component synthesis or VCS run cannot establish an FPGA checkpoint or CPU
migration.
