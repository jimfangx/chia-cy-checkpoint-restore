# Readout graft in the existing lowered circuit

Iteration 238 adds `NativeCheckpointInPlaceGraft.generate`. It reconstructs the
source/context/global identity through the checked in-place access API, then
inserts a transaction router, immutable functional descriptor ROM and physical
CE bank inside the existing enclosing root. It replaces the previously exposed
bank sideband ports with local wires and exposes the explicit capture interface.
It never instantiates a second enclosing simulator or moves the selected target.
Original functional ports, instance paths, ancestor clocks and storage annotations
remain unchanged. Router/CE logic uses the proven raw clock.

The returned files include both original-path synthesis and implementation XDC.
They are generated by the actual constraint consumer against the grafted circuit,
with validated literal placement paths, without the companion's extra `network`
hop. The binding hashes source/context, grafted circuit, global descriptor identity,
adapter/router/CE RTL, placement and constraint files. Existing instance/port/module
collisions and changed source, dependency or context contracts reject.

An independent auditor reconstructs every root port, wire, instance, connection,
original statement and untouched module from the original input. It checks the
entire adapter against the independently audited original descriptor/CE/router
contract, including all ROM entries and raw clocks, and compares original XDC
placement. Native synthesis runs on localhost; VCS execution runs on EDA SP2.
Exact commands, diagnostics and receipts are retained under
`automations/checkpoint_loop/runs/aws-f2/iteration238/`.

The bounded graft passes **7,101 EDA SP2 checks / four cuts / 136 words / 522
stalls**, continuing through cycle **419**, with five debug waveforms. Native
synthesis retains **1,091 LUTs / 595 registers / three BUFGCEs** and proves
**199** raw ancestor/router/endpoint clocks. OOC setup/hold estimates are
**+2.052/−0.074 ns**; full-image closure remains pending. Native/EDA matching
binds **630 inputs / 59 sources** and rejects six coherently rehashed adapter
mutations; eight additional rehashed circuit/clock/hierarchy/constraint/scope/owner
mutations reject independently. Independent settled-wave reconstruction proves both ancestor counters
advance during **872** frozen raw-clock edges at cuts **25/78/193/339**, with
no selected target advance. Compiled CE corruption stops on the first physical
read at target cycle **25**, check **55**.

All **253 Scala / 24 localhost synthesis / 43 EDA scopes**, **313 checkpoint
Python / 40 loop tests** and retained **ASan/UBSan/host/FCFS** checks pass.
The final combined audit passes. Plans and initialized manager YAMLs retain
